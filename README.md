# code-replay

Craft 에 정리해 둔 코딩 가이드를 **단계별 완성 코드**로 다시 쌓고, 그 커밋들을 브라우저에서 타이핑 애니메이션으로 재생하는 따라 치기 플레이어입니다. 화면은 터미널처럼 생겼고, 오른쪽에 그 단계의 가이드 설명이 붙어 있습니다.

## 쓰는 법

1. 아래 터미널에 `ls` → `cd <가이드>` → `play` (또는 홈 화면에서 가이드 카드를 클릭).
2. 가운데 에디터에서 코드가 한 글자씩 쳐지는 걸 보며 내 에디터에 따라 칩니다.
3. 오른쪽 「단계 설명」 에서 왜 이렇게 짜는지 읽고, 「가이드 소개」 에서 전체 그림을 봅니다.
4. 단계 재생이 끝나면 터미널에 다음 단계 링크가 뜹니다. 완료한 단계는 이 브라우저에만 기억됩니다.

### 터미널 명령

| 명령 | 하는 일 |
| --- | --- |
| `ls` | 가이드 목록 (가이드 안에서는 단계 목록) |
| `cd <가이드>` / `cd ..` | 가이드 열기 / 나가기 |
| `play [단계]` | 단계 재생. `play next`, `play prev` |
| `read [단계\|intro]` | 설명만 보기 |
| `stages`, `branches` | 단계 / 실험 브랜치 목록 |
| `pause`, `resume`, `restart`, `next`, `prev` | 재생 제어 |
| `speed [ms]` | 타이핑 속도 (글자당 ms) |
| `done [단계]` | 완료 표시 토글 |
| `help`, `keys`, `clear` | 도움말, 단축키, 지우기 |

`Tab` 으로 가이드와 단계 이름을 자동 완성하고, `↑` `↓` 로 이전 명령을 불러옵니다.

### 단축키 (`Esc` 로 입력창을 벗어난 뒤)

| 키 | 동작 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `h` `l` | 한 줄 뒤로 / 앞으로 |
| `H` `L` | 변경 단위 뒤로 / 앞으로 |
| `p` `n` | 이전 / 다음 커밋 |
| `[` `]` | 이전 / 다음 단계 |
| `r` | 이 커밋 처음부터 |
| `-` `+` | 느리게 / 빠르게 |
| `/` `:` | 명령어 입력 |

주소창의 `#/<가이드>/<단계>/<커밋>` 으로 특정 위치를 바로 열 수 있습니다.

## 가이드 데이터 만들기

가이드 원본은 `../code-replay-src/<slug>/` 에 둡니다 (형식은 `code-replay-src/CONTRACT.md`).

- 단계마다 태그(`stage-<id>`)가 붙은 git 저장소
- `guide.json`, `intro.md`, `stages/<id>.md`

```bash
pnpm export            # ../code-replay-src → public/data/*.json
pnpm dev               # 로컬에서 보기
pnpm test && pnpm build
```

`public/data` 는 커밋해 둡니다. main 에 push 하면 GitHub Actions 가 Pages 로 배포합니다.
